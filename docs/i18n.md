# Internacionalización del admin

## Verificaciones

Prueba temporal con `vue-i18n@11.4.16`, Node 24.22 y Vite 8.3.8.

- `node probe.mjs` confirmó que el `t` desestructurado de `i18n.global` devuelve la clave inglesa con `fallbackFormat`. Conservó punto, coma, dos puntos, interrogación, exclamación, apóstrofo y comillas dobles. Con el catálogo plano en español, `t` devolvió «Puntuación» y `te` devolvió `true` para la misma clave con punto.
- El mismo comando confirmó `Hello {name}` → `Hello Ada` sin catálogo inglés y las tres ramas plurales para 0, 1 y 3 en ambos idiomas. `<i18n-t scope="global">` insertó un enlace en el slot nombrado dentro de «Abre …».
- En claves y valores, escribir `{'{'}`, `{'}'}`, `{'@'}` y `{'|'}` produce llaves, arroba y barra vertical literales. Reservar la barra vertical sin escapar para plurales y las llaves sin escapar para variables. El dólar `$` se escribe directamente.
- `vite build` generó `dist/assets/es-DH66PXg0.js` (0,28 kB, 0,21 kB gzip) aparte de la entrada (92,54 kB, 32,05 kB gzip). Estas métricas corresponden a la prueba mínima.

## Mensajes del API

Los mensajes para el usuario son frases completas en inglés con punto final. Los nombres de campos, el estado HTTP y los códigos de error conservan el contrato del API. Los valores de la petición y los identificadores se omiten del mensaje o se guardan en datos estructurados. En auditoría, el registro se identifica por `record_id` y los detalles de la operación se guardan en `diff`.

El inventario se construyó revisando `api/src/hooks` y `api/src/lib`. Se incluyeron constructores de errores, `fieldError`, validadores que retornan cadenas, objetos de error, mensajes persistidos y resúmenes de auditoría. Las rutas que usan la respuesta predeterminada de PocketBase siguen usando esa respuesta. Los errores internos de programación o de registro se conservan en inglés cuando ya están en ese idioma.

Las plantillas y las vistas previas de correo se mantienen en el idioma del cliente. Los títulos de sesiones y notas que contienen datos de una reserva conservan sus valores dinámicos como datos del registro.
