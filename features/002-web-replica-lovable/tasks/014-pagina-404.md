# 014 - [Web] Página 404

- **Prioridad:** 14
- **Estado:** Completado
- **Depende de:** 001, 006
- **Fase:** Fase 3: Páginas estáticas

## Objetivo

La página 404 replica la del original: mensaje centrado a pantalla completa con enlace a inicio.

## Contexto

El original (error de ruta no encontrada) renderiza `div.flex.min-h-screen.items-center.justify-center.bg-background.px-4` > `div.max-w-md.text-center` con `h1.text-7xl.font-bold.text-foreground` `404`, `h2.mt-4.text-xl.font-semibold.text-foreground` `Page not found`, `p.mt-2.text-sm.text-muted-foreground` `The page you're looking for doesn't exist or has been moved.` y, en `div.mt-6`, un enlace a `/` `inline-flex items-center justify-center rounded-md bg-primary px-4 py-2 text-sm font-medium text-primary-foreground transition-colors hover:bg-primary/90` con el texto `Go home`. El original no muestra header ni footer en esta pantalla. `404.astro` actual usa estilos provisionales de `slate`.

## Alcance

- Reescribir `web/src/pages/404.astro` con el marcado anterior. Dado que el original no muestra header ni footer, la página no usa `BaseLayout` con header/footer: añadir a `BaseLayout.astro` una prop opcional `bare?: boolean` (por defecto `false`) que omite `Header` y `Footer` y el `min-h-screen` del `<main>`.
- Título `Page not found`; descripción `The page you're looking for doesn't exist or has been moved.`
- Límites: sin cambios en el resto de páginas.

## Criterios de aceptación

- [x] `dist/404.html` contiene `404`, `Page not found` y el enlace `Go home` a `/`, y no contiene `<header` ni `<footer`.
- [x] Las demás páginas siguen mostrando header y footer.
- [x] En `bun run dev`, abrir una ruta inexistente muestra la 404 centrada.
- [x] `bun run lint`, `bun run format:check`, `bun run check`, `bun run test` y `bun run build` pasan en verde.
